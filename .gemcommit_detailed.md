# Instructions

Analyde the following `git diff` and generate a detailed Conventional Commit message with the following parts:

1. Type (for exampple, `feat`, `fix`, `refactor`, `docs`, `style`, `test`, etc.)
2. Scope (optional, in round brackets)
3. Short description
4. Detailed body explaining the changes
5. Note any breaking changes

- Write in British English
- Use the definite or indefinite articles with nouns at the beginning of sentences or anywhere.
- Start the sentence with a initial uppercase letter 
- Start the sentences with the gerund (for example, "Fixing the bug" instead of "fi bug").
- Use the present continuous tense for actions.
- Always use the French quotation marks — `«` and `»` instead of simple or single English quotation marks for articles, special meanings, direct or indirect source.
